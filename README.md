# handmade-support-app

ハンドメイド作家の販売活動/ブランディングを支援するアプリ（ポートフォリオ）
在庫管理に加え、写真やタイトルの改善を通じて売上やブランド価値の向上をサポートする。

## ✨背景
ハンドメイド作品においては、写真が売上に大きく影響する。
一方で、既存サービスではこれらのノウハウはガイド記事として提供されることが多く、
出品時に活用されにくいと感じた。

## ✨特徴
・在庫管理機能  
・写真改善のためのガイド表示   

## ✨コンセプト
クリエイターの独創性を尊重しながら、販売活動とブランディングに必要な気づきを提供する

## ✨UX観点
ユーザーが直感的に操作できるよう、一覧画面ではカード形式で作品を表示し、視認性と操作性の向上を意識しました。
カード全体をクリック可能にすることで、ユーザーが迷わず詳細ページへ遷移できるようにしています。
配色はナチュラルで落ち着いたトーンを採用し、作品そのものが引き立つように設計しました。

## ✨技術観点
Ruby on Railsを用いたCRUD機能の実装に加え、シンプルな構成を意識し、保守性の高いコード設計を心がけました。
管理者向けの簡易登録機能を追加し、実運用を想定したデータ登録フローを実現しています。
ルーティングやコントローラの責務を整理し、可読性と拡張性を意識した実装を行いました。

## ✨品質観点
機能単位での動作確認に加え、「ユーザーが安心感を持って使えるか」という観点でテストを実施しました。
例えば、一覧から詳細画面への遷移や、ダミーボタン押下時のメッセージ表示など、ユーザー体験に影響する部分を重点的に確認しています。
